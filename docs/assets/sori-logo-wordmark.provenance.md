# Sori logo wordmark: provenance and usage notice

- **Filename:** `sori-logo-wordmark.png`
- **SHA-256:** `047f8733e878f3d453464d68bf29fdcba609d618ab8c5dc29a52924c93a4480f`
- **Dimensions and format:** 2200 × 760 RGBA PNG with true alpha and transparent corners.
- **Generation method:** Two distinct symbol candidates were generated with the built-in OpenAI image-generation tool through `codex exec --enable image_generation`. The wrapper exposed `gpt-5.6-sol` for the generation session; the image model ID was not exposed and is intentionally not asserted.
- **Reference:** User-supplied image at `C:/Users/hoang/Downloads/ChatGPT Image Sep 7, 2026, 07_39_52 PM.png`, used only as directional inspiration. The mark was redrawn as a simplified aquatic familiar and was not copied pixel for pixel.
- **Third-party images:** None. No stock, web, or third-party image assets were used.
- **Candidate selection:** Candidate A used a circular multi-fin gesture. Candidate B used a compact koi-whale head flowing into a serpentine loop with a swept fin. Candidate B was selected because its silhouette remains legible at README scale, has a clearer listening-loop gesture, and carries less visual noise.
- **Wordmark method:** `Sori` was authored programmatically as custom 5 × 7 bitmap glyph grids for `S`, `o`, `r`, and `i`. No external font was used and no font name is claimed. The glyphs use deliberate square modules and optical tracking.
- **Post-processing:** The generated candidate was chroma-key cleaned to alpha with Pillow using the local OpenAI image-generation helper, cropped to content, resized, and composited with the custom bitmap wordmark using a local Pillow script. No white matte, app tile, glow, or added background was included.
